🎯 PROJECT GOAL

You’ll create a pipeline that:

✅ Pulls your portfolio code from GitHub

⚙ Builds a Docker image

🚀 Runs your website in a Docker container

🔁 Rebuilds automatically whenever you push new code to GitHub




🧱 STEP 1 — Confirm your folder & GitHub repo structure

Make sure your GitHub repo (and local folder) looks like this:

Portfolio/
│
├── index.html
├── style.css
├── script.js
├── Dockerfile
└── Jenkinsfile


You already pushed your HTML earlier, so now just add the Dockerfile and Jenkinsfile.




🐳 STEP 2 — Create a Dockerfile

In your Portfolio project folder, create a file named Dockerfile

Add this content:

# Use a lightweight web server
FROM nginx:alpine

# Remove default nginx files
RUN rm -rf /usr/share/nginx/html/*

# Copy your portfolio files into nginx
COPY . /usr/share/nginx/html

# Expose port 80 for HTTP traffic
EXPOSE 80

# Start nginx server
CMD ["nginx", "-g", "daemon off;"]

Save the file and push it to GitHub:

git add Dockerfile
git commit -m "Added Dockerfile for Jenkins deployment"
git push




⚙️ STEP 3 — Create Jenkinsfile (Pipeline Script)

In the same folder, create another file named Jenkinsfile and add this:

pipeline {
    agent any

    stages {
        stage('Clone Repository') {
            steps {
                git branch: 'main', url: 'https://github.com/Likhitha1605/Portfolio.git'
            }
        }

        stage('Build Docker Image') {
            steps {
                bat 'docker build -t portfolio:latest .'
            }
        }

        stage('Stop Old Container') {
            steps {
                bat 'docker stop portfolio || exit 0'
                bat 'docker rm portfolio || exit 0'
            }
        }

        stage('Run New Container') {
            steps {
                bat 'docker run -d -p 8081:80 --name portfolio portfolio:latest'
            }
        }
    }

    post {
        success {
            echo "✅ Portfolio deployed successfully at http://localhost:8081"
        }
        failure {
            echo "❌ Build failed! Check logs."
        }
    }
}


Then push this to GitHub:

git add Jenkinsfile
git commit -m "Added Jenkinsfile for CI/CD automation"
git push



🧩 STEP 4 — Configure Jenkins to Use Docker

Open Jenkins → Manage Jenkins → Plugins

Go to Available plugins

Search and install:

✅ Docker

✅ Docker Pipeline

Wait for the installation to finish.

Then go to:

Manage Jenkins → Tools → Docker installations → Add Docker


Fill in:

Name: docker

Install automatically: Unchecked

Docker executable path:

C:\Program Files\Docker\Docker\resources\bin


Click Save ✅



🧱 STEP 5 — Create a Jenkins Pipeline Job

Go to Jenkins Dashboard → New Item

Name: Portfolio_CICD

Select: Pipeline

Click OK

In the configuration page:

Scroll to Pipeline section

Choose:

Definition: Pipeline script from SCM

SCM: Git

Repository URL:

https://github.com/Likhitha1605/Portfolio.git


Branch: main

Save ✅



🚀 STEP 6 — Run the Pipeline

Go to Jenkins dashboard → open your job → click Build Now

Wait for the console output.
Jenkins will:

Clone your GitHub repo

Build Docker image

Stop old container

Run your portfolio site inside Docker

✅ When you see:

Portfolio deployed successfully at http://localhost:8081


👉 Open browser → http://localhost:8081

🎉 Your portfolio website is now running automatically inside Docker, deployed by Jenkins!






🔁 STEP 7 — Automate with GitHub Webhook (optional but powerful)

This lets Jenkins rebuild automatically when you push to GitHub.

Go to your GitHub repo → Settings → Webhooks → Add Webhook

In “Payload URL”, enter:

http://localhost:8080/github-webhook/


Content type: application/json

Event: “Just the push event”

Click Add webhook

✅ Now, every time you git push, Jenkins rebuilds and redeploys your site automatically.
